
# Life-OS: AI Digital Wellbeing Dashboard

Life-OS is a Streamlit-based dashboard that analyzes daily screen time data using a synthetic dataset. 
It visualizes app usage trends, tracks daily screen-time goals, and leverages the Gemini API to provide personalized productivity and digital wellbeing recommendations based on user habits.

## Features

- 📊 Visualizes 14 days of screen time data
- 📅 Filter usage by date
- 🎯 Set a daily screen-time goal
- 📈 Interactive charts and KPI metrics
- 🤖 AI-powered digital wellbeing insights using Gemini
- 🔗 Shareable accountability link

- ## Tech Stack

- Python
- Streamlit
- Pandas
- Google Gemini API
